# Демо «Голосовой ввод»

Откройте `index.html` в браузере. Для локального сервера запустите из корня репозитория:

```sh
python3 -m http.server 8000
```

Шапка и системная область настраиваются в `js/demo-frame.js`. Сцена находится в `index.html`. Каркас сохраняет исходный размер сцены 1600 × 900 и прокручивается в небольшом окне.

Компонент, токены и шрифты взяты из [table-widget](https://github.com/pershmary/table-widget/tree/57ff125). Источник компонента указан в `vendor/ui-kit/SOURCE.md`.
